# Multilingual public creator scan

Research date: 2026-11-01

## Scope

There is no reliable, complete public index of every technology influencer in every language. Social profiles are frequently login-gated, region-specific, rate-limited, or changed without notice. This is therefore a curated public scan across languages and creator types relevant to Neural Ant: AI education, software building, automation, career development, product storytelling, and creator-led distribution. The accounts and sites below are research inputs, not endorsements or proof of performance.

## What was implemented from the scan

1. **Profile readiness checklist.** My profile now shows a percentage based only on present, user-provided fields: resume, contact, target roles, skills, location/work mode, experience, education/certifications, and professional links. Missing items are named with plain-language guidance; the app does not invent data.
2. **Freshness evidence.** Matching roles now expose a `New` or `Checked … ago` label. The API returns both `first_seen` and `last_seen`, so users can distinguish a newly discovered role from a role that was merely rechecked.
3. **Research-to-product rule.** Every creator insight is translated into a testable workflow, a visible evidence boundary, or a measurable experiment. We do not copy a creator's branding, scrape followers, or install plugins merely because a creator mentions one.

## Next experiments

- Create a synthetic public demo in Telugu, Hindi, Spanish, Portuguese, and Arabic with the same underlying scoring and evidence model.
- Add private feedback buttons such as `relevant`, `not relevant`, and `already applied`, then evaluate ranking with Recall@K and nDCG@K.
- Publish one privacy-safe weekly workflow: role freshness, fit evidence, tailored resume review, and supervised form fill.
- Build partner kits for career centers and immigrant professional communities with translated onboarding, a one-page privacy explanation, and a synthetic demo account.
- Measure profile completion → match opened → role saved → user-started application → user-submitted application → interview. Do not optimize for application volume alone.

## Plugin decision

No plugin was installed for this scan. Public web research and the local repository already provide the capabilities needed. A future email, CRM, analytics, or design integration should be connected only when a specific workflow needs it and only after the user chooses the provider and permissions.
